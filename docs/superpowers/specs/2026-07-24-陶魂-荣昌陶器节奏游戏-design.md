# 「陶魂」— 荣昌陶器节奏技艺游戏 · 设计文档

## 概述

- **类型**：静态网页游戏（单页 HTML5）
- **视觉风格**：写实质感风——陶土肌理、釉色光泽、窑火光影，沉浸式还原
- **目标用户**：对传统文化感兴趣的普通玩家
- **核心玩法**：节奏/时机类休闲操作，五个工艺环节串联
- **技术约束**：纯前端，无框架，HTML5 + CSS + Vanilla JS，单文件亦可拆分

## 核心循环

```
选择器型 → 练泥 → 拉坯 → 修坯 → 刻花 → 烧制 → 评分展示 → 重新挑战
```

每个环节独立评分，最终汇总总评。玩家可重复挑战以追求更高分数。

## 五个工艺环节详细设计

### ① 练泥 —「揉泥去浊」
- **玩法**：陶泥团在画面中央旋转揉动，气泡随机冒出（带"啵"的视觉提示），玩家在气泡消失前点击戳破
- **操作**：点击/触屏
- **难度曲线**：气泡出现频率和速度逐渐加快
- **评分维度**：命中率、连击数、漏掉气泡数
- **时长**：约 15-20 秒
- **画面**：揉动的赭红色陶泥团，质感湿润有光泽，气泡半透明

### ② 拉坯 —「轮转成形」
- **玩法**：陶轮旋转，器壁高度在波动中周期变化，出现"提拉区"和"下压区"的视觉提示，玩家在正确时机点击对应按钮
- **操作**：两个按钮（提拉↑ / 下压↓），或键盘方向键
- **难度曲线**：波动速度从慢到快，窗口时机会越来越窄
- **评分维度**：时机精准度（Perfect / Good / Miss）、器型完整度
- **时长**：约 20-25 秒
- **画面**：写实陶轮旋转，湿泥坯体逐渐成形，手部轮廓在两侧

### ③ 修坯 —「刀走泥落」
- **玩法**：坯体旋转，表面出现"多余区域"标记，刀具从上方靠近，玩家在标记对准时刻点击削去
- **操作**：点击/空格键，长按削深、短按削浅
- **难度曲线**：标记区域变小、旋转加快
- **评分维度**：切削精准度（削多了扣分、削少了留痕）
- **时长**：约 15-20 秒
- **画面**：旋转的坯体，金属修坯刀，泥屑飞落

### ④ 刻花 —「铁笔生花」
- **玩法**：器壁上显示预设纹样（缠枝纹/回纹/蕉叶纹等荣昌传统纹样），光标沿纹样轨迹移动，偏离则警告
- **操作**：鼠标跟随/手指拖动，按住开始刻画，松开暂停
- **难度曲线**：纹样复杂度递增，允许偏差范围递减
- **评分维度**：轨迹贴合度、完成速度、是否中断
- **时长**：约 20-30 秒
- **画面**：素坯表面，刻痕逐渐浮现，金色/暗色纹路线条

### ⑤ 烧制 —「烈火成器」
- **玩法**：窑炉温度计显示当前温度，目标温度区间上下波动。左侧"加柴"升温、右侧"减柴"降温。玩家拖动滑块或点击两侧来保持温度在最佳区间内
- **操作**：左右区域点击/拖动，或键盘 ← →
- **难度曲线**：目标区间变窄，温度惯性变大（加柴后延迟升温）
- **评分维度**：温度在最佳区间的时长占比、釉色成色
- **时长**：约 25-30 秒
- **画面**：窑炉内部视角——火光摇曳、温度计、釉色随温度变化（从陶土本色→光泽→窑变色彩）

## 最终评分与展示

- 每个环节 0-100 分，加权平均 = 总评
- 展示完成的陶器 3D 旋转效果（CSS 3D 模拟）
- 评定等第：神品(95+) / 精品(85+) / 良品(70+) / 习作(<70)
- 分享卡片：可以截图保存

## 技术实现

### 文件结构
```
/
├── index.html          # 入口，加载所有资源
├── css/
│   └── style.css       # 全局样式 + 环节专属样式
├── js/
│   ├── main.js         # 游戏主控：流程调度、分数管理
│   ├── stages/
│   │   ├── knead.js    # ① 练泥
│   │   ├── throw.js    # ② 拉坯
│   │   ├── trim.js     # ③ 修坯
│   │   ├── carve.js    # ④ 刻花
│   │   └── fire.js     # ⑤ 烧制
│   ├── ui.js           # UI 组件：HUD、过渡动画、评分面板
│   ├── audio.js        # 音效管理（可选：Web Audio API 简单合成）
│   └── particles.js    # 粒子系统：气泡、泥屑、火星
├── assets/
│   ├── textures/       # 陶土、木纹、釉色纹理图
│   └── sounds/         # 音效文件（可选）
└── docs/
    └── superpowers/
        └── specs/
            └── 2026-07-24-陶魂-设计文档.md
```

### 关键技术点
- **Canvas 2D**：所有环节画面用 Canvas 绘制，保证流畅度
- **requestAnimationFrame**：游戏主循环
- **触屏 + 鼠标兼容**：pointer events 统一处理
- **CSS 纹理**：噪点、光泽等效果用 CSS `background` + `filter` 实现，减少图片依赖
- **音效**：使用 Web Audio API 的 OscillatorNode 合成简单音效，无需音频文件

### 兼容性
- 目标：现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）
- 移动端：触屏操作完全兼容
- 加载方式：可本地打开，也可部署到任何静态服务器

## 开发顺序

1. 搭建框架：index.html + main.js + Canvas 渲染循环
2. 实现核心 UI：环节切换、分数 HUD、过渡动画
3. 逐个实现五个环节（按流程顺序：练泥→拉坯→修坯→刻花→烧制）
4. 实现最终评分展示画面
5. 添加粒子效果、音效、视觉润色
6. 移动端适配与测试
